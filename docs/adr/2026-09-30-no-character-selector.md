# 2026-09-30. No character selector
Status: accepted
Summary: The engine has no character selection screen (launch menu or lobby toggle); a player is the scene's humans_play_as, else --as, else the Human.

## Context
ADR 0011 gave `re2` a launch screen where the player picked a body (Human, Cheddar the rat, then wizard, cowboy, alien, robot), and the online lobby had a
"PLAY AS" toggle. The owner does not want a character selector in the engine or in any game built on it: what a player is belongs to the game
(`player.humans_play_as`, kart drivers in a race lobby), not to a generic engine screen.

## Decision
- No selection screen exists. `re2` plays as the scene's `player.humans_play_as`, else `--as` / `RE2_CHARACTER`, else the Human.
- The launch menu (`Phase::Menu`, the six-model 3-D scene, `ui::screens::menu_layout`, the `menu` screen of `ui-shot` / `ui-check`) and the lobby's
  `OnlineAction::ToggleCharacter` (the C key and the PLAY AS button) are deleted. `menu::backdrop_scene` remains as the plain studio behind the connect form.
- A launch without `--connect` and without a scene policy shows the connect form first; its PLAY SOLO button (Esc) starts a local game. `--connect` and
  `--as` start at once, as before.
- The race lobby's animal picker (`NextDriver` / `PrevDriver`) is a game feature (karts) and stays. `Character`, costumes, protocol character codes and
  bots' rosters stay: they are gameplay data, not UI.

## Consequences
Nothing generated by `new-game` or shipped with the engine can show a character selector. A game that wants players to choose a body writes that choice
itself (a rule, a lobby, a custom client). Undo: ADR 0011 describes the removed screen; the code is in git history before this decision.
