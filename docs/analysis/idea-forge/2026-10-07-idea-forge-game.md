# Idea Forge run: the Idea Forge game itself (2026-10-07)

The first run, done by hand before the CLI existed: the game-idea generator as a native 2D game. The full narrative is `docs/analysis/2026-10-07-idea-forge-feedback.md`; this file restates its ranked findings in the machine-readable form `scripts/idea_forge.py digest` reads. Minutes are wall-clock estimates by the agent that did the run.

## The game

`examples/2d/idea-forge.game2d.json` (generated by `examples/2d/idea-forge/build.py`): strike an anvil, get an idea (YOU / BUT / PUSHBACK / GOAL / STORY) from 8.15 billion non-repeating combinations; lock, save, back; published as release idea-forge-v1.

## Idea fit

The task was a tool rather than a game mechanic, and it fitted the engine apart from randomness and text: everything else (state, buttons bound to keys, persistence, sound, music, reels) expressed directly in rules and ui widgets.

## What worked

validate and verify were fast and named the fix; frame caught every layout bug before a window was opened; persist with the loaded event made saved state a three-line rule.
